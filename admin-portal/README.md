# VisaDesk administrator workspace

This frontend is served by the unified application at `/admin`. Start the API package with `npm run dev`, then open `http://localhost:4000/admin`. It uses the same server origin as the client workspace and `/api/v1` API.

Only an account with the `ADMIN` role can use administrator API operations. The UI does not replace server-side role checks.

See the [repository setup guide](../README.md) and [admin guide](../visa-slot-agency-api-auto-setup/docs/ADMIN_GUIDE.md).
